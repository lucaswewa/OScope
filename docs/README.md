# Documentation

| Document | What it is |
|---|---|
| [Goals](goal.md) | What OScope sets out to do, in the project owner's words |
| [Implementation plan](implementation-plan.md) | Scope, the decisions made while planning, the architecture for all three milestones, the Milestone 1 phase overview, outlines of Milestones 2 and 3, risks and points for review |
| [Milestone 1 phase specifications](milestone-1/phases.md) | The goal, scope, example, "done when" and tests for each phase: U01–U06 (upstream `teta-wot`), and P00–P54 with P02b |
| Hardware | The real instrument: camera, SDK, stage controller, lights and host. Created in P02b as `hardware.md` |
| Architecture decision records | One record per significant decision, numbered across the project. Created in P00 under `adr/` |
| Implementation notes | One file per phase: what was built, how to try it, deviations and follow-ups. Created in P00 under `milestone-1/notes/` |

See the plan's [documentation conventions](implementation-plan.md#11-documentation-conventions) for how these documents are organised.
