# Logging

The server's log, as it is written.

- **The records,** the newest at the foot: each its time, level, where it came from, and what it says. Press one for its fields beside the list.
- **Filters:** *At least* a level, from *Trace* to *Error*, and *Text* to find.
- **The tail:** the list follows each new record. Scrolled up, it holds where it is, and a button counts the records that came since; press it to follow again.
- **The counts** of each level so far.
- **The daily files:** each day's log, to download as it is, a record a line.
