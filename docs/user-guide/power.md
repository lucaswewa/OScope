# Power

The service and the computer it runs on. Each asks first, and waits for its name typed.

- **Restart…** restarts the service: the page says it is restarting, then that the service restarted, once the new server answers. Settings saved for the next start, such as the system's or an extension installed, take effect.
- **Reboot…** and **Shut down…** the computer.
- **A hardware job running,** such as a capture or a scan, refuses them, saying which; *Force it…* goes on anyway.
- **A dry run,** where the administrator has set one, only says what each would have run.
