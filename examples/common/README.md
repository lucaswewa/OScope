# Shared HTTP example helper

R07 simulator examples use this library for temporary data, HTTP requests, action/job polling and bounded server shutdown. Static example pages are unchanged source fixtures. The obsolete managed-sidecar helper and unused vendor routing are excluded from the Linux container rebuild.

Use the [R07 manual procedure](../../docs/phases/r07-microscope-workflows.md#manual-test) for the supported smoke commands. This helper has no independent executable.
